# ESP32 Status Light

Локальный статусный светильник на ESP32-S3 с прошивкой, настольным клиентом и корпусом для 3D-печати.

## Корпус для 3D-печати

**[Открыть интерактивную 3D-модель](https://ksenkso2.github.io/esp32-status-light/)**

**[Скачать готовый ZIP-комплект для мастера](case/esp32-status-light-case.zip)**

В комплекте четыре детали: основание, крышка, рассеиватель и USB-вставка. Основной материал — обычный PLA; для рассеивателя рекомендуется натуральный PLA. Размеры, ориентация деталей, поддержки и сборка описаны в [PRINT.txt](case/PRINT.txt).

Рендер работает без сервера и внешних зависимостей: можно вращать модель, разносить детали, показывать плату и переключать цвет RGB-светодиода.

## Структура проекта

- `firmware/` — прошивка PlatformIO для ESP32-S3-DevKitC-1 и совместимой платы S3-N16R8.
- `client/` — настольный GUI, CLI и Ubuntu tray client.
- `case/` — параметрический корпус CadQuery, STL, ZIP и офлайн 3D-просмотрщик.

Локальный просмотр модели на macOS:

```sh
open case/index.html
```
